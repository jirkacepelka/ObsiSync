Připojení Obsidianu

1. Nainstaluj plugin ObsiSync

{{if index .D "Available"}}

Stáhnout plugin (ZIP)

  1. Rozbal ZIP do složky <tvůj vault>/.obsidian/plugins/ (vznikne složka obsisync).
  2. V Obsidianu otevři Nastavení → Komunitní pluginy, vypni omezený režim a zapni ObsiSync.

Na telefonu je nejsnazší použít plugin BRAT (Beta Reviewers Auto-update Tester) s repozitářem jirkacepelka/ObsiSync, nebo zkopírovat složku pluginu z počítače.

{{else}}

Tento build serveru neobsahuje soubory pluginu. Stáhni je z GitHub Releases repozitáře jirkacepelka/ObsiSync, nebo použij plugin BRAT.

{{end}}

2. Přihlas se

V nastavení pluginu ObsiSync vyplň:

Adresa serveru{{index .D "ServerURL"}}
Jméno{{.User.Username}}
Heslotvoje heslo

Klikni na Přihlásit, vyber vault ze seznamu a klikni na Připojit. Hotovo.

{{end}}
