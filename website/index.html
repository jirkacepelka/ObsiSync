How it works

From zero to synced in three steps

No config files, no database to set up, no cloud accounts.

1

Start the server

One Docker container. Paste a YAML into ZimaOS, or run one command on a VPS. Open the web page and create your admin account.

$ docker run -p 8080:8080 \
  ghcr.io/jirkacepelka/obsisync
2

Enter three fields

Install the plugin in Obsidian and fill in the server address, your name and password. That's the whole configuration.

sync.example.com
jirka

3

Pick a vault

The plugin shows the vaults your account can use. Pick one and click Connect. Every device you connect stays in sync.

Features

Everything you need, nothing you have to tune

⚡

Near-instant sync

The server pushes “something changed” over WebSocket; devices fetch only what's new.

🔀

Smart conflicts

Edits to different parts of a note are merged line by line. When they overlap, both versions are kept.

🕘

Version history

Every change is kept. Preview any old version in the browser and restore it with one click.

💾

Scheduled backups

Per vault: every hour, 6 hours, day or week. Keep them 7 days to forever. Optional ZIP copies.

👥

Users & sharing

Share a vault with family or a team as owner, editor or read-only. Log out lost devices instantly.

🛡️

Server always wins on connect

A new or empty device can never overwrite your vault. Local leftovers go to Obsidian's trash, not the server.

🪶

Tiny footprint

A ~27 MB image using a few tens of MB of RAM. Go + SQLite, amd64 and arm64.

🌍

8 languages

English, Čeština, Slovenčina, Deutsch, Français, Español, Italiano and Polski.

Conflicts, handled

Edited on two devices at once? Nothing is lost.

Every write is a compare-and-swap against the version the device last saw. If someone got there first, SimpleSync runs a three-way merge. Changes on different lines simply combine. If the same line changed on both sides, the server version stays and yours is saved next to it as Note (conflict … iPhone).md.

  • Edit beats delete – always
  • Unicode file names work across macOS, Windows and Linux
  • Safety prompt before a sync would delete half your vault

Install

Pick where it runs

App Store → + → Install a customized app → YAML, delete what's there and paste this. Then open http://<zimaos-ip>:8080.

name: obsisync
services:
  obsisync:
    image: ghcr.io/jirkacepelka/obsisync:latest
    container_name: obsisync
    restart: unless-stopped
    ports:
      - target: 8080
        published: "8080"
        protocol: tcp
    environment:
      TZ: Europe/Prague
    volumes:
      - type: bind
        source: /DATA/AppData/obsisync/data
        target: /data
x-casaos:
  architectures:
    - amd64
    - arm64
  main: obsisync
  category: Utilities
  title:
    en_us: SimpleSync
  tagline:
    en_us: Simple self-hosted sync for Obsidian
  icon: https://raw.githubusercontent.com/jirkacepelka/SimpleSync/main/server/internal/web/static/icon.svg
  index: /
  port_map: "8080"
  scheme: http

Point a DNS A record (e.g. sync.example.com) at your VPS, then run this. Caddy gets the HTTPS certificate automatically.

mkdir simplesync && cd simplesync
curl -O https://raw.githubusercontent.com/jirkacepelka/SimpleSync/main/deploy/docker-compose.caddy.yml
DOMAIN=sync.example.com docker compose -f docker-compose.caddy.yml up -d

Anything with Docker – a NAS, a Raspberry Pi, a home server:

docker run -d --name obsisync -p 8080:8080 -e TZ=Europe/Prague \
  -v $PWD/data:/data --restart unless-stopped \
  ghcr.io/jirkacepelka/obsisync:latest
Then in Obsidian: install the SimpleSync plugin (from the server's Plugin page or via BRAT), enter address, name and password, pick a vault.
🔒

Your notes never leave your server

The plugin talks only to the server address you enter – a server you run yourself. No telemetry, no third-party service, no account with anyone else. Your password is used once to get a device token and is never stored on the device. Use HTTPS (Caddy or Tailscale) to encrypt traffic in transit.

FAQ

Questions

Is it free?

Yes. SimpleSync is open source under the MIT license. You only pay for the machine it runs on – often a box you already own.

Does it replace Obsidian Sync?

It covers the same job – keeping vaults in sync between devices – but runs on your own server. Obsidian Sync is a great paid service; SimpleSync is for people who want to self-host.

What happens when I connect a new device?

If the vault on the server has content, the server always wins: the device becomes an exact copy and nothing is uploaded from it. Anything that was only on the device is moved to Obsidian's trash, so nothing is lost.

Can I use it outside my home network?

Yes. On a VPS you get HTTPS automatically. At home, the easiest way is Tailscale or a Cloudflare Tunnel.

Is it end-to-end encrypted?

No – the server can read the notes, which is what makes version previews and server-side backups possible. Since you run the server, that's you.

How do I back up the server?

Everything lives in one data folder. Copy it, or use the built-in scheduled backups with optional ZIP files.
